# RoadGuard VM deploy

The project runs on an Oracle Cloud `VM.Standard.A1.Flex` (4 OCPU ARM, 24 GB,
Always Free) with Ubuntu 24.04. Any Linux VM with Python 3.11+ works the same way.

## One-shot setup

```bash
curl -L https://raw.githubusercontent.com/<owner>/<repo>/main/deploy/setup.sh -o /tmp/roadguard-setup.sh
sudo bash /tmp/roadguard-setup.sh
```

The script installs the system prerequisites, creates the `roadguard` user and
`/opt/roadguard`, `/var/lib/roadguard`, `/etc/roadguard`, clones the repo to
`/opt/roadguard/repo`, builds the venv, copies `.env.example` to
`/etc/roadguard/env` (mode 0600, first run only) and installs `roadguard.service`.

## Layout on the VM

| Path | Role |
|---|---|
| `/opt/roadguard/repo` | the repository checkout (`roadguard_agent.py`, `roadguard_api.py`, `policy.yaml`, `webapp/`, `data/`) |
| `/opt/roadguard/venv` | Python environment |
| `/etc/roadguard/env` | configuration, read by the unit (`EnvironmentFile`) |
| `/var/lib/roadguard` | SQLite database, LangGraph checkpoints, Chroma index, backups |

`roadguard.service` runs `uvicorn roadguard_api:app --host 0.0.0.0 --port 8000`
with `PYTHONPATH=/opt/roadguard/repo`. Keep port 8000 closed on the public
interface; expose the API through a Cloudflare tunnel and the operator pages
through a private network (the hosts in `ROADGUARD_PRIVATE_HOSTS`).

Models: the agent calls a local Ollama (`OLLAMA_BASE_URL`, default
`http://localhost:11434`); pull the model named in `AGENT_LLM_PROVIDER`
(production: `qwen2.5:7b`).

## After setup

1. Fill `/etc/roadguard/env`: `ROADGUARD_JWT_SECRET` (generated by the script),
   `ROADGUARD_PASSPHRASE_HASH`, `AGENT_LLM_PROVIDER`, `ROADGUARD_PRIVATE_HOSTS`,
   `ROADGUARD_CORS_ORIGINS`, `ROADGUARD_APPROVAL_BASE_URL`, e-mail settings.
2. Seed the RAG index once (the script prints the command): it reads
   `data/mini_corpus.jsonl` with `roadguard_agent.seed_from_jsonl`.
3. `sudo systemctl start roadguard.service` and check
   `curl -s http://127.0.0.1:8000/health`.

## Updating

```bash
sudo -u roadguard git -C /opt/roadguard/repo pull --ff-only origin main
sudo systemctl restart roadguard.service
```

## Logs

```bash
sudo journalctl -fu roadguard.service
```

Every completed run prints its trace block (the same lines the `/trace` page
shows) followed by a metrics line.
